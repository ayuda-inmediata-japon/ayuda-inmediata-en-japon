NIVEL 1 · PRINCIPIANTES · LECCIÓN 01

En el konbini

Al terminar podrás: Pedir algo, aceptar o rechazar una bolsa y agradecer.

Cómo estudiar: escucha la pronunciación en el vídeo cuando esté disponible; lee la escritura japonesa, repite tres veces sin prisa y practica el ejemplo en voz alta. La romanización es orientativa; no sustituye escuchar a un hablante nativo.

Expresión 1

これをください

Pronunciación: Kore o kudasai

Significado: Esto, por favor

Cuándo usarla: Señala el producto. La partícula を (o) marca lo que pides.

Ejemplo real: Señalando una bebida: これをください。 / Kore o kudasai. / Esto, por favor.

🎤 Practica: primero lento, después a velocidad natural; deja una pausa para repetir.

Expresión 2

袋は要りません

Pronunciación: Fukuro wa irimasen

Significado: No necesito bolsa

Cuándo usarla: Útil cuando preguntan si quieres una bolsa. Puedes decirlo antes de pagar.

Ejemplo real: Dependiente: 袋はご利用ですか。 / Fukuro wa go-riyō desu ka. / ¿Necesita bolsa? Tú: 袋は要りません。

🎤 Practica: primero lento, después a velocidad natural; deja una pausa para repetir.

Expresión 3

ありがとうございます

Pronunciación: Arigatō gozaimasu

Significado: Muchas gracias

Cuándo usarla: Forma cortés de agradecer al personal. No necesitas inclinarte profundamente.

Ejemplo real: Al recibir el cambio: ありがとうございます。 / Arigatō gozaimasu. / Muchas gracias.

🎤 Practica: primero lento, después a velocidad natural; deja una pausa para repetir.

✍️ Comprueba lo aprendido

Si llevas tu propia bolsa, ¿qué dices?

Ver respuesta y explicación

Pedir que repitan

Expresión 1

すみません

Pronunciación: Sumimasen

Significado: Disculpe / Perdón

Cuándo usarla: Sirve para llamar la atención y disculparse ligeramente; a veces expresa gratitud.

Ejemplo real: Antes de preguntar: すみません。 / Sumimasen. / Disculpe.

🎤 Practica: primero lento, después a velocidad natural; deja una pausa para repetir.

Expresión 2

もう一度お願いします

Pronunciación: Mō ichido onegaishimasu

Significado: Otra vez, por favor

Cuándo usarla: Pide que repitan. Combínalo con すみません para sonar más cortés.

Ejemplo real: すみません、もう一度お願いします。 / Sumimasen, mō ichido onegaishimasu.

🎤 Practica: primero lento, después a velocidad natural; deja una pausa para repetir.

Expresión 3

ゆっくり話してください

Pronunciación: Yukkuri hanashite kudasai

Significado: Hable despacio, por favor

Cuándo usarla: Hablar más lento no es lo mismo que repetir exactamente la frase.

Ejemplo real: すみません、ゆっくり話してください。 / Sumimasen, yukkuri hanashite kudasai.

🎤 Practica: primero lento, después a velocidad natural; deja una pausa para repetir.

🎤 Practica: primero lento, después a velocidad natural; deja una pausa para repetir.

Repaso y primera conversación

Al terminar podrás: Unir saludos, preguntas y agradecimientos.

Cómo estudiar: escucha la pronunciación en el vídeo cuando esté disponible; lee la escritura japonesa, repite tres veces sin prisa y practica el ejemplo en voz alta. La romanización es orientativa; no sustituye escuchar a un hablante nativo.

Expresión 1

日本語を勉強しています

Pronunciación: Nihongo o benkyō shite imasu

Significado: Estoy estudiando japonés

Cuándo usarla: Permite comunicar tu nivel y pedir paciencia.

Ejemplo real: はじめまして。日本語を勉強しています。 / Mucho gusto. Estoy estudiando japonés.

🎤 Practica: primero lento, después a velocidad natural; deja una pausa para repetir.

Expresión 2

少し分かります

Pronunciación: Sukoshi wakarimasu

Significado: Entiendo un poco

Cuándo usarla: No implica que hables con fluidez; evita que supongan que comprendes todo.

Ejemplo real: 日本語は少し分かります。 / Nihongo wa sukoshi wakarimasu.

🎤 Practica: primero lento, después a velocidad natural; deja una pausa para repetir.

Expresión 3

ありがとうございます

Pronunciación: Arigatō gozaimasu

Significado: Muchas gracias

Cuándo usarla: Repasa su uso al recibir ayuda y al terminar una consulta.

Ejemplo real: 教えてくれてありがとうございます。 / Oshiete kurete arigatō gozaimasu. / Gracias por enseñármelo.

🎤 Practica: primero lento, después a velocidad natural; deja una pausa para repetir.

¿Qué sigue después?

Al dominar este nivel, se pueden continuar los cursos de japonés cotidiano y conversación práctica. Si no entiendes una indicación médica, laboral o jurídica, pide interpretación profesional; las frases educativas no sustituyen ese servicio.
